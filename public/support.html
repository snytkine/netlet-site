Support

Help for NetLet chat, the local network messaging app

Need help or found a problem? Open an issue at github.com/snytkine/netlet-site/issues. Tell us your app version (Settings → About), your operating system, and what happened. Please do not include private information.

Quick answers

The User Manual and the FAQs on this site explain how NetLet works. Common problems are below.

I can't connect to the host

  • Make sure both computers are on the same local network (the same Wi-Fi or office network).
  • Check the address. The host's address is shown in the status bar at the top of the chat while hosting, and you can copy it from the Server view.
  • If the host chose a custom port, include it after the address, for example 192.168.1.20:44444.
  • Some guest or "isolated" Wi-Fi networks stop computers from talking to each other. Try a different network or ask the network's owner.

macOS asks about Local Network access, or nothing connects

  • Open System Settings → Privacy & Security → Local Network and make sure NetLet is switched on.
  • When hosting, allow incoming connections if macOS asks, or check that the firewall under System Settings → Network → Firewall is not blocking NetLet.

The host went offline

NetLet first tries to reconnect to the host. If that fails, another person in the chat can be asked to take over as host, and only if they agree.

Where are my messages stored? How do I delete them?

Only on your own computer. Delete them with Clear message history in Settings. See the Privacy Policy for details.
